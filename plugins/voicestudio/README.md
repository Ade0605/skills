# VoiceStudio skill (vendored)

The `voicestudio` skill from [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)
at commit `40c5e3c`, copied unchanged from `skills/voicestudio/SKILL.md`.

It teaches Claude to use a running VoiceStudio backend (default `http://localhost:3900`)
for speech generation, transcription, cloning, dubbing and its MCP endpoint.
It does not install the VoiceStudio app itself; get that from the
[releases page](https://github.com/debpalash/VoiceStudio/releases/latest).

Install: `/plugin install voicestudio@ade0605-skills`
